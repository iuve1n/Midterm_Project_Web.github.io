# LeafLoop

LeafLoop is a front-end demo for a local book exchange in Astana. Readers can browse sample listings, offer a book, review example swaps, and view a reader profile.

## Pages

- `index.html` introduces LeafLoop and shows recent listings.
- `browse.html` displays sample books and search, genre, and condition controls.
- `list-book.html` contains the listing form and a guide to book condition.
- `swaps.html` shows example pending, planned, and completed swaps.
- `profile.html` displays a reader profile and books available to trade.

## Technologies

The pages use HTML, custom CSS, Bootstrap, and SVG illustrations. CSS Grid and Flexbox handle the page layouts. Bootstrap provides the navigation collapse and form styles.

## View the site

Open `index.html` in a browser. The Bootstrap files are included in the project. The listing form uses browser validation, but this demo does not save submitted listings.
